## How to use the evidence

Lead with the proof point that best answers the employer's question. Translate the evidence into the capability it demonstrates and the value that capability creates in the target role.

The positioning sequence is:

**Evidence → factual boundary → role context → strongest relevant truth → employer value → persuasive candidate voice → QA → release.**

Accuracy is a hard constraint. It is not the entire positioning objective.

## Positioning rules

- Select the strongest evidence relevant to the capability being evaluated.
- Translate metrics into employer value rather than leaving them as isolated numbers.
- Keep each metric at the funnel level supported by its source.
- Separate scope, contribution, observed outcome, and direct causality where the distinction materially affects the claim.
- Keep internal governance language out of employer-facing prose unless the boundary itself is relevant to the question.
- Never answer an objection the employer has not raised.
- If evidence does not support a requested factual claim, do not manufacture one. Route to the strongest adjacent truth that actually answers the employer's underlying need.

## Public-safety standard

The public registry excludes compensation policy, references, contact data, private application answers, sensitive employer diagnostics, personnel information, and unapproved internal metrics.

## Standard

The strongest public positioning is the strongest employer-relevant case the evidence supports. Truth defines the boundary; positioning makes the value unmistakable.
