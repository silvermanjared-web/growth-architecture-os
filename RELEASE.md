# Portfolio OS v1.0

## Release intent

v1.0 marks the point at which the public portfolio operates as one coherent, inspectable professional system rather than a collection of related repositories.

## What is true at v1.0

- Growth Architecture OS is the canonical architecture and common-language layer.
- Supporting repositories have distinct roles and federation contracts.
- The AI operating-system reference is executable and tested.
- Intelligence and execution layers expose explicit capabilities and receipts.
- Marketing Ops Playbooks contains the full-cycle learning model.
- Context engineering runs through implementation in one public system.
- Private-to-public publication has an executable security boundary.
- The portfolio has an executive index, proof ledger, capability catalog, federation status, synthetic scenarios, ADRs, and private-scale/public-proof explanation.
- Visual language is intentionally editorial and understated rather than dashboard-like.

## Stability promise

v1.0 does not mean the portfolio will never change.

It means the architecture is sufficiently coherent that future work should improve evidence or capability without casually changing the underlying operating model.

## Release rule

Do not create another major portfolio architecture initiative unless a real professional or operating need cannot be solved inside the current system.
