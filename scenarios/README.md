# Try the System

These synthetic scenarios demonstrate how the portfolio behaves as one operating system without requiring private data or a live production environment.

Each scenario has two layers:

1. **Jared's reasoning** — how I frame the decision.
2. **System behavior** — how the federated public architecture supports that reasoning.

The scenarios are intentionally realistic but fictional.

## Scenarios

1. [Paid Search CPA Spike](paid-search-cpa-spike.md) — separate media performance from funnel, measurement, and release effects.
2. [Budget Reallocation](budget-reallocation.md) — move capital using downstream economics rather than channel preference.
3. [Measurement Break](measurement-break.md) — refuse false optimization when signal integrity is compromised.
4. [Context-to-Execution Failure](context-to-execution.md) — repair an AI/design workflow by fixing context and authority before adding more prompting.

## What these prove

The system is not a linear chain of automated decisions.

It is a decision architecture:

**context → diagnosis → method → evidence → bounded action → receipt → learning → better next brief.**
