# Positioning

This directory translates governed career evidence into employer-facing positioning.

## Objective

**Accuracy is a hard constraint. Hireability is the positioning objective.**

The evidence system in `../00-positioning/claims/` controls what may be claimed. This layer controls how supported truth is selected, sequenced, translated into employer value, and communicated at the appropriate level of seniority.

## Positioning rule

Lead with the strongest relevant supported truth and what it demonstrates for the employer. Keep evidence controls underneath the narrative unless a boundary is material to the question.

Never answer an objection the employer has not raised.
