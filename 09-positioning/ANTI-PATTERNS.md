# Positioning Anti-Patterns

Avoid these patterns in employer-facing public material:

- opening with a disclaimer;
- explaining unsupported claims before stating supported ones;
- treating factual restraint as a differentiator by itself;
- presenting governance mechanics before business value;
- translating every metric into what it does not prove;
- reducing enterprise work to tactical execution;
- substituting generic leadership adjectives for concrete scale and decisions;
- burying the strongest proof below repository architecture;
- using compliance language where confident candidate voice is appropriate.

The evidence system should prevent exaggeration silently. The positioning system should make supported value obvious.
