# _meta

Repository metadata, actively maintained.

| File | What it holds |
|---|---|
| `content-map.json` | machine-readable map of this repository's content |
| `source-index.md` | index of sources behind the material here |

## This is not an archive

The leading underscore is a sorting convention, not a retirement marker. An
earlier automated governance sweep read the underscore as "retired" and wrote an
archive notice here declaring that nothing in this directory governs. That was
wrong, and this note replaces it.

The distinction matters for tooling as much as for readers: a directory marked
retired gets excluded from indexing and validation, so a mislabel here quietly
removes real metadata from view rather than announcing a problem.
