# ChatGPT Handoff

Treat this directory as a reference implementation, not as authority to act outside it.

Before proposing or executing work:

1. discover the declared capability;
2. identify whether it is read, propose, or write;
3. preserve the target boundary;
4. require confirmation when the contract says confirmation is required;
5. return a concise receipt;
6. refuse requests that require undeclared authority.

Prefer fewer moving parts over new registries or policy layers.
